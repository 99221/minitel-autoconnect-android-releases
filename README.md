# Minitel AutoConnect for Android

This public repository contains installable APK releases only. The application source is maintained separately.

Download the latest signed APK from [Releases](https://github.com/99221/minitel-autoconnect-android-releases/releases/latest). On your Android phone, open the APK and allow installation from your browser or file manager when Android asks.

After installation, enter your EMSE portal username, password, and target Wi-Fi name. Grant location and Wi-Fi permissions, keep the system Location switch enabled, and set this app's Location permission to **Allow all the time** in Android settings for checks after a reboot. The app displays its current status and a Diagnostics report.

Android can defer background jobs to save power, so refresh timing is approximate. If the app does not connect, open Diagnostics and check the reported Wi-Fi and permission state.
